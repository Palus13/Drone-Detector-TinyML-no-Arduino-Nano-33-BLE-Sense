# Drone-Detector-TinyML-no-Arduino-Nano-33-BLE-Sense
Detecção em tempo real do som de um drone usando uma rede neural TinyML (DS-CNN) rodando **100% embarcada** em um Arduino Nano 33 BLE Sense Rev2 — sem nuvem, sem Wi-Fi, sem servidor. Áudio captado pelo microfone PDM onboard, processado e classificado localmente em menos de 1 segundo, com indicação visual (LED RGB) e via Bluetooth (BLE).
