# Arduino Firmware

## Required libraries (Arduino IDE -> Tools -> Manage Libraries)

- **Arduino Mbed OS Nano Boards** (Boards Manager — required to recognize the board)
- **Chirale_TensorFlowLite**
- **ArduTFLite**
- **arduinoFFT** (author: kosme)
- **ArduinoBLE**

The `PDM` library ships with the board core (no separate install needed).

## `drone_detector/` — main firmware

Final sketch: captures audio from the PDM microphone, computes MFCC in
C++, runs the neural network (TensorFlow Lite Micro), and reports the
result via RGB LED and Bluetooth (BLE).

Files:
- `drone_detector.ino` — main code
- `model.h` — the `.tflite` model converted to C++ (generated by `python/06_export_arduino_assets.py`)
- `mfcc_tables.h` — MFCC math tables, extracted from `librosa` (generated by the same script)

**LED indicators:**
| LED | Meaning |
|---|---|
| 🔵 Solid blue | Initializing |
| 🟢 Solid green | No drone |
| 🔴 Solid red | Drone detected (confidence >= 50%) |
| 🔴 Fast-blinking red | Drone detected (confidence >= 80%) |
| 🔴 Very fast, continuous blinking | Fatal error during initialization |

**Bluetooth:** advertises as `"DroneDetector"`. Connect with a generic BLE
app (e.g. [LightBlue](https://punchthrough.com/lightblue/)) to see:
- State (0 = background, 1 = drone, 2 = drone with high confidence)
- Human-readable status string ("No Drone" / "Possible" / "Drone")
- Exact probability (float, 0.0–1.0)

Updates are only sent over BLE when the state changes or the probability
shifts by more than 0.05, to avoid flooding the connection.

## `record_and_dump/` — recording utility

Helper sketch used **only during fine-tuning data collection** (not the
detection firmware). Records 5 seconds of audio from the PDM microphone
on command and streams it over Serial to the PC. Used together with
`python/03_record_via_arduino.py`.

## Memory parameters

`kTensorArenaSize` (RAM reserved for the neural network) is tuned for the
current model. If you train a different model (more layers/channels),
this value may need recalibrating — see the "journey" section in the main
README for the process used to find it.
